# 在边界条件下强调安全性
取消剪贴板写入可能遗留明文。 crates/os/src/clipboard.rs:144–159, 193–205, 224–232 通过 stdin 向 wl-copy 传送文本，在取消、超时或宿主关闭时用 SIGKILL 终止进程组。wl-clipboard 2.2.1 会先把 stdin 写入 /tmp/wl-copy-buffer-*，完成后才删除临时文件和目录。若终止发生在文件创建后、删除前，部分或全部文本会以仅当前用户可读的明文留在磁盘上，即使写入未获确认。现有关闭测试把输入写到 /dev/null（crates/os/src/clipboard/tests.rs:198–214），没有覆盖这条清理路径。建议改用不创建具名明文临时文件的写入后端，并补充回归测试，验证传输中途取消或超时后不遗留文本文件。
