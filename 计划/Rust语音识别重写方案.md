# 语音输入后续计划

本文列出语音输入的待实现事项。定时录音、识别协议、复制重试和快捷键用法见使用说明。当前面板的「语音输入」页提供录音、状态和设置查询入口。插件从宿主共享配置的 `voice_input` 节读取识别与录音参数。 [语音输入使用说明](<../docs/语音输入.md>) · [面板与命令注册](<../plugins/voice-input/src/lib.rs#L309>)

## 待实现的用户入口

- **面板配置编辑。** 通过插件命令校验并原子保存端点、模型、录音时长和凭据。表单只显示凭据配置状态，保存时提示音频与凭据发送至配置的端点。更新仅影响后续会话。
- **录音控制和设备选择。** 提供提前停止及选择麦克风的入口。会话 ID 关联控制请求和录音结果。提前停止复用定时结束的音频收尾路径，保留截止点前已采集的数据，仅触发一次识别。指定设备不可用时报告原因。录音、识别和复制共享任务槽。
- **桌面通知。** 提示录音、识别和复制阶段，以及可操作的失败状态。仅在剪贴板后端确认成功后显示「已复制」。通知不包含全文、音频或凭据。

自动测试使用可控音频输入、环回识别 mock 和 fake 剪贴板，覆盖配置保存失败、短录音尾部、设备断开和重复停止。集成验收在私有 PipeWire 与 Wayland 会话中验证实际设备选择、剪贴板读回和通知显示。开发部署和安装验收沿用 Cargo 产物与现有插件布局。 [部署辅助脚本](<../scripts/deploy-plugins.sh>) · [Arch 安装模板](<../packaging/release/PKGBUILD.in>)

## 有明确调用方后再评估的接口

进程内 PCM 转录只返回文本，并与录音会话共享任务槽。接口需显式定义目标插件、请求归属、输入上限、deadline 和取消语义。调用方超时或取消时应能终止底层处理并隔离迟到转录结果。 [宿主架构](<../关键设计/程序架构.md>)
