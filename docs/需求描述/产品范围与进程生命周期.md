# 产品范围与进程生命周期

> 核对基线：`0058b7e`。本页描述已实现的产品范围；代码路径用于追溯现行实现，不承诺永久固定。此次文档重整未启动用户桌宠或连接真实桌面。

## 目标与非目标

DeskWaifu 在 Linux Wayland 上把 Live2D 模型显示为透明 layer-shell 覆盖窗口，并提供独立控制面板和本机命令接口。Qt 应用是唯一支持的入口，不维护旧 GLFW demo 或原生窗口后端。

要求合成器支持 `wlr-layer-shell`；不承诺 X11、任意 Wayland 合成器、其他 CPU 架构或跨发行版二进制兼容。当前 Cubism Core 构建使用 Linux x86_64 库。Qt-only 指窗口技术，不表示所有业务编译在宿主内。

## 需求与验收

- **PROC-01 启动入口**：`deskwaifu` 启动后端，`deskwaifu-control` 启动独立 GUI，`deskwaifu-ctl` 通过 IPC 操作已有后端。`--models_dir` 指定模型目录，`--config` 指定主配置；默认路径见[配置与保存](配置与保存.md)。
- **PROC-02 能力缺失**：插件分别初始化，单个失败只回滚自身并报告诊断；不能把桌面初始化失败伪装成普通窗口成功。其他健康插件可继续工作，平台进程存活不等于桌宠已可用。
- **PROC-03 Spawn**：控制面板已连接时不重复启动。未连接时在当前用户运行目录加共享启动锁并检查进程；已有非僵尸 `deskwaifu` 时只尝试连接。无法检查进程、加锁或找到程序时显示失败，不强行启动第二个后端。
- **PROC-04 独立存活**：启动器优先使用控制面板同目录的可执行文件，其次 `PATH`，以默认后端参数 detached 启动。关闭 GUI 不停止后端；不能声称保留自定义 `--config` 或其他旧进程参数。
- **PROC-05 Shutdown**：连接后发送 `quit`；检测到后端但尚未连接时不能发送退出命令。等待期间避免重复操作，退出后按钮回到启动状态。
- **PROC-06 Respawn**：连接时可请求重启；先确认可执行文件存在，再发 `quit`，等连接断开且旧进程退出后才启动新进程。退出被拒绝或默认 10 秒超时则报错，不强杀、不启动重叠实例；操作中禁止重复 Spawn/Respawn。
- **PROC-07 退出与清理**：停止入口、任务和模型 worker 后释放窗口；模型 GL 对象必须在所属线程及有效 context 下收尾。收尾失败必须报告失败，不能以窗口已关闭作为 GPU 清理成功证明。细则见[GPU 生命周期](GPU生命周期.md)。
- **PROC-08 信号入口**：`SIGUSR1` 切换可见性，`SIGUSR2` 请求移动到焦点显示器；后者受合成器能力限制且不持久化显示器选择。`toggle`/`focus` helper 可不初始化图形应用直接控制已有进程，发现规则见[插件架构](插件架构.md)。

## 现行设计与维护入口

平台只负责引导、事件循环和插件生命周期；业务由 desktop、ipc、speech、perception、reading_clip 提供。GUI 页面属于各自插件，系统页拥有启动和重启辅助类；详见[GUI 插件](GUI插件.md)。开发运行必须显式设置插件目录，见[Qt 窗口](Qt窗口.md#构建与开发运行)。

不要让多个模型进程争用同一 IPC socket。当前产品没有自动迁移 Waifuland 数据：旧配置和模型需用户迁入 `deskwaifu/`，旧脚本、命令、socket 和合成器规则需更新，详见[根 README 升级指南](../../README.md#upgrading-from-waifuland)。不要借文档验证停止或改写用户进程。

- [插件宿主测试](../../platform/plugin/tests/)与[桌面集成命令测试](../../platform/tests/DelegatePluginCommandsTest.cpp)：生命周期、失败、命令往返与退出；私有合成器 smoke 见[测试与门禁](测试与门禁.md)。

现状限制：启动检测基于当前 UID 的进程名/可执行文件名，不提供多配置实例编排；插件不是崩溃隔离边界。线上服务部署与实体桌面效果仍需专门验收。
