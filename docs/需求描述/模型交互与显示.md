# 模型交互与显示

> 核对基线：`0058b7e`。需求描述可观察行为，内部缓存、采样和线程细节标为现行设计。没有在本次文档整理中运行实体显示器或指定 GPU 验证。

## 目标与边界

用户能发现、加载和切换本机 Live2D 模型，控制动作、表情、皮肤、口型、视线、位置与显示范围。模型文件由用户提供，不随文档重整下载或分发；加载目录结构见[模型准备](../../README.md#model-setup)。平台能力以[Wayland 集成](Wayland集成.md)为准。

## 需求与验收

### 模型与动作

- **MODEL-01**：从默认 `$XDG_CONFIG_HOME/deskwaifu/models/`（回退 `~/.config/deskwaifu/models/`）、CLI 指定目录及 `additional_model_dirs` 发现模型。每个模型通过其 `.model3.json` 加载；可查询模型列表、当前模型和状态。
- **MODEL-02**：选择成功才切换活动模型；无效选择或加载失败保留旧模型及控制状态。选择同一活动模型不重建其会话 token；实际切换必须清除旧外部控制，并拒绝使用旧 token 的快捷键请求。
- **MODEL-03**：支持已有模型的动作、普通表情、皮肤、自动眨眼、物理与口型。不存在的动作/表情明确失败；目录列出资源不保证 SDK 加载或启动必然成功。普通表情按 `emotion_timeout` 恢复，`-1` 表示不自动恢复。
- **MODEL-04**：模型匹配的 `.vtube.json` 快捷键显示名称、按键、动作、启用/激活状态和不支持原因。当前支持 `ToggleExpression` 独立持久开关及淡入淡出/定时停用；普通表情超时不能清除持久开关。换模型清除开关并刷新列表。
- **MODEL-05**：控制面板激活时跨 TAB 响应快捷键；不提供全局绑定。Tab/Shift+Tab 不移动面板焦点；自动重复不反复切换。其他键保留文本/数值编辑行为。不支持的按键或冲突不妨碍可用的按钮操作；松开停用及其他动作仅显示不支持，不伪装执行成功。

### 输入、透明度与视线

- **MODEL-06**：模型区域接收点击、拖动和滚轮；其余透明背景及裁剪外区域穿透。默认左击上/下半身触发表情/动作，右击切换模型，中击切换皮肤，滚轮缩放；以模型资源和编辑状态允许的操作为限。
- **MODEL-07**：平时与悬停透明度是独立的 `0..1` 乘数；启用悬停时命中模型使用 hover 值，其他情况使用 idle 值，不把两者相乘。模型自身 alpha 保留。零透明度仍保留原模型输入轮廓，离开后可恢复，不因视觉透明就穿透；编辑手柄不算模型悬停。
- **MODEL-08**：鼠标注视半径为有限非负数，限制归一化视线向量长度并保留方向；零表示居中，不影响外部 `set_look`。全局注视仅在支持的 KWin 桥上提供，失效时保留表面局部输入，不能伪造坐标或合成拖动。
- **MODEL-09**：隐藏时移除模型内容输入区域，恢复显示时只接受与当前模型/尺寸/隐藏状态匹配的帧；不使用旧模型快照。隐藏不等于所有编辑输入消失，屏幕编辑可能保留独立输入区域；详见[应用状态与控制](应用状态与控制.md)。

### 变换、裁剪与显示器

- **MODEL-10**：位置、缩放及裁剪作为同一编辑事务预览、应用保存或取消。缩放必须有限且在 `0.1..10`，位置有限；非法值不得部分修改。裁剪用当前输出表面的左上角逻辑整数像素，宽高为正，不是模型浮点坐标。
- **MODEL-11**：裁剪外透明且穿透，裁剪不改变模型原位置/缩放。保存用户请求矩形，不保存与当前输出求交后的缩小矩形；完全在屏幕外允许不可见，并提供移回屏幕入口。
- **MODEL-12**：拖动越过阈值进入屏幕编辑；拖模型只移动模型，顶部手柄同时移动模型与裁剪，边/角只调整裁剪。松开保留编辑框，双击框边或顶部手柄尝试保存并退出，失败保留草稿可重试。编辑中不得触发模型点击、快捷键或双击语音。
- **MODEL-13**：面板独占编辑时屏蔽模型鼠标键/轮/键盘业务，但不停止指针及悬停跟踪。取消或所属连接断开恢复已保存值；Reset 保存居中、缩放 1 和关闭裁剪。冲突与重试规则见[配置与保存](配置与保存.md)。
- **MODEL-14**：显式选择显示器必须完成/取消当前编辑；成功后保存连接器名称、居中、清除裁剪并保留缩放，保存失败尝试恢复旧显示器。启动显示器缺失时回退第一个并尝试保存；写入失败告警，仍使用可读配置位置，不阻止可用输出启动。
- **MODEL-15**：输出切换期间拒绝输入；热插拔重绑定取消编辑，尺寸变化取消屏幕编辑。Hyprland 本地拖动释放可跨屏并继续编辑，但手柄和面板拥有的编辑不跨屏；不支持全局指针时拖动保持局部。

### 渲染设备

- **MODEL-16**：`auto` 为默认；显式 PCI 地址以 CLI `--render-device`、`DESKWAIFU_RENDER_DEVICE`、配置顺序选择。不支持的设备启动失败，不能静默退回自动。
- **MODEL-17**：GUI/IPC 修改保存的是下次启动选择，不能在运行中切换 context；返回保存值、活动值和 `restart_required`。保存失败恢复确认值，丢失设备显示不可用，Respawn 后应用；CLI/环境覆盖仍优先。

## 现行设计与限制

- [模块职责](模块职责.md)解释模型身份、确定性目录、会话与缓存。**同名模型 IPC 选择最后一个排序匹配、启动默认选择第一个**是已知实现差异，不在本次整理中提升为新兼容承诺或修复。
- 命中轮廓使用约 10 像素块采样，不是逐像素精确判定；编辑时可接收整输出输入。CPU 快照与几何来自同一完成帧，可能领先最后成功呈现帧。
- [Qt 窗口](Qt窗口.md)采用逻辑分辨率渲染及 CPU RGBA readback/upload，不是 HiDPI 原生模型分辨率、DMA-BUF 或零拷贝。独立 GPU 减少显示 GPU 的模型驻留，不消除呈现开销，并增加带宽成本。
- [窗口状态机](窗口状态机.md)是窗口策略依据；资源预算和失败清理见[GPU 生命周期](GPU生命周期.md)。

## 验收依据

实现位于[desktop 插件](../../plugins/desktop/README.md)。[插件测试目录](../../plugins/desktop/tests/)中的 `ModelCatalogTest.cpp`、`ModelSessionTest.cpp`、`ModelHotkeysTest.cpp`、`ModelKeyboardTest.cpp`、`ModelWindowStateTest.cpp`、`TransformEditorTest.cpp`、`OutputSettingsTest.cpp`、`HoverOpacitySettingsTest.cpp`、`MouseLookSettingsTest.cpp`、`RenderDeviceSettingsTest.cpp` 分别提供对应策略检查。

`ModelRenderThreadTest.cpp` 与 `ModelRegionRenderTest.cpp` 检查真实 Cubism/EGL、快照与像素；[私有 KWin smoke](../../tests/qt_headless_smoke.py)检查实际 layer-shell、输入路由、多输出及模型命令。夹具策略通过不等于真实点击穿透；软件 GPU auto 通过不等于指定 PCI 或跨 GPU 已验证。实体鼠标、显示质量及真实设备仍需专门授权验收。
