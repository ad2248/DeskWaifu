# 配置与保存

宿主从 `$XDG_CONFIG_HOME/deskwaifu/config.jsonc` 加载配置。`XDG_CONFIG_HOME` 未设置或为相对路径时，使用绝对 `HOME` 下的 `.config/deskwaifu/config.jsonc`。顶层 JSONC 对象以插件 ID 为键，插件管理各自的值。文件缺失时使用空配置，首次写入才创建文件。 [宿主入口](<../../apps/deskwaifu/src/main.rs>)

- 文件须为权限恰为 `0600` 的普通文件，文件本身不能是符号链接。格式为 UTF-8 JSONC，可使用行注释、块注释和尾逗号。上限为 1 MiB，数组和对象合计最多嵌套 64 层（含顶层）。重复的顶层插件 ID 会被拒绝。 [配置存储](<../../crates/runtime/src/config.rs>)
- 宿主保存时重新读取并校验磁盘内容，再原子写入新的目标区段。其他区段及目标值之外的文本与注释保留。快照在保存成功后刷新。编辑文件时应避免与宿主同时写入，常规外部编辑可在重启后应用。 [配置存储](<../../crates/runtime/src/config.rs>)
- `terminal` 的变换事务用同一 IPC 连接持有。应用保存草稿，取消或断连恢复编辑前状态，保存失败保留草稿。语音输入配置放在 `voice_input` 区段，设置查询只返回密钥是否已配置。 [terminal 配置和编辑](<../../plugins/terminal/README.md>) · [语音输入配置](<../语音输入.md#配置麦克风和识别服务>)

## 导入 Live2D 桌面配置

迁移工具接受一个 UTF-8 桌面 `config.json` 文件路径和可选的绝对目录及启动模型路径。它将建议的 `terminal` 区段写入标准输出，将需要人工处理的项目写入标准错误，不修改输入与目标文件。 [迁移工具](<../../scripts/migrate-live2d-config.py>)

```sh
python3 scripts/migrate-live2d-config.py /path/to/config.json \
  --model-directory /path/to/models \
  --startup-model /path/to/models/Haru/Haru.model3.json
```

检查建议并将需要的字段合并到共享配置。模型名称需提供明确的 `.model3.json` 路径。位置与缩放需要手动调整。裁剪保留输出局部逻辑坐标，合并时可保留目标已有的位置与缩放，并预览裁剪效果。工具仅输出 `terminal` 配置，不复制资源或凭据。 [模型配置与编辑](<../../plugins/terminal/README.md>)
