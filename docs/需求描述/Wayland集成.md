# Wayland 集成（#80）

> 基线：`0058b7e`。本文区分规范要求、现行设计与证据边界：约束性措辞保留原文要求；现行行为和限制不自动升级为规范；测试描述不代表本次迁移已执行验证。插件所有权以[插件架构](插件架构.md)为权威。

- `QtDesktopWindow` 使用 Qt 和 LayerShellQt 管理窗口、呈现上下文及表面切换，将指针、键盘和关闭事件转换给 `IDesktopWindowEvents`，后者是借用的、由应用拥有的事件接收端。窗口回调不会获取应用单例。ID 在每个 QScreen 的生命周期内稳定；移除一个输出不会改变其余输出的身份，但重新连接会分配新 ID。当前输出消失时，后端重新绑定到第一个剩余输出；没有剩余输出或重新绑定失败时，请求关闭应用。
- 仅 `CompositorAdapter` 查询 Hyprland 或 Sway。响应读取的期限为 250 ms，且必须在达到 16 KiB 之前遇到 EOF；达到此大小即失败。命令读取及等待子进程退出共享 250 ms 预算，在延迟回收之前另有 250 ms 清理等待。Hyprland 套接字连接就绪及响应读取各自有 250 ms 预算，并非单个端到端期限。能力报告 `Available`、`Unsupported`、`Unavailable` 或 `Failed`，但命令读取失败（包括响应过大）归入 `Unavailable`；套接字读取保留 `Failed`。通用后端仍接收表面局部的指针/键盘事件。Hyprland 的可选全局光标在本地屏幕编辑释放时检测跨输出模型拖动。Hyprland 和 Sway 支持通过 SIGUSR2 切换到焦点输出；这不会持久化输出选择。缺失能力不会伪造坐标。
- `InputListener` 独立使用 KWin D-Bus/脚本光标桥提供全局视线跟随，通过 16 ms 定时器采样，与呈现无关。有效采样映射为当前输出的局部坐标；不可用或过期的采样不影响表面事件可用性，桥会重试加载。这不提供 KWin 焦点输出切换或跨输出拖动；`CompositorAdapter` 将 KWin 视为通用合成器。
- `OutputController` 从复制的 `OutputSnapshot` 值选择输出，使用稳定的 `OutputId` 而不是向量位置；只有窗口处理 QScreen 对象。选择失败保持变换不变。跨输出拖动成功时，按逻辑输出高度缩放，并在提交变换前将缩放限制到应用有效区间。
- `OutputSettings` 按连接器名称处理启动和控制面板的输出选择请求。显式切换会将名称与居中坐标、已清除的裁剪一起持久化，保留缩放。启动名称不可用时，回退到第一个枚举输出，并保存此替代值。变换编辑阻止显式选择；保存失败时尝试恢复旧输出。启动回退的持久化是尽力而为：写入失败会记录警告，但保持可用输出及可读配置中的位置可用。

Qt/LayerShellQt 负责协议 configure 确认和 EGL 集成。应用等待 Qt 窗口暴露后再绑定呈现用 QOpenGLContext。更换输出时保留该上下文，失败时在可能的情况下回滚到旧屏幕。模型资源属于独立渲染线程的离屏上下文（默认 Qt，选择设备时使用显式 EGL）；RGBA 帧被读回并上传到窗口呈现。关闭时先重新绑定模型上下文并释放模型资源及渲染目标，再释放呈现 FBO、上下文和窗口。所需上下文无法重新绑定时，GPU 清理可能留到进程退出。

Sway 无头冒烟测试在两个输出上运行真实模型，覆盖双向切换、IPC 存活及优雅 GPU 关闭。独立私有 KWin 测试覆盖双输出窗口切换、在 `kscreen-doctor` 可用时移除/重新添加活动输出、键盘焦点、实际点击穿透及 GPU 帧传输。CI 以 1 和 1.5 两种缩放运行 KWin 冒烟测试，后者还测试安装后的应用。单元测试覆盖输出选择/变换策略、设置持久化与回滚、合成器传输失败及 KWin 光标桥恢复。

## 需求验收与证据边界

- 核对稳定输出身份、选择失败不改变换、编辑守卫和持久化/回滚行为；分别检查合成器能力，不把 KWin 光标桥当作焦点输出切换或跨输出拖动支持。
- 传输超时按上述分阶段预算验收，不误称端到端 250 ms；命令与套接字错误分类按现状区分。
- 结合对应合成器冒烟和单元测试验证；上下文无法重绑时不承诺完成 GPU 清理，本文未提供本次实测结果。
