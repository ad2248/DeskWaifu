# 应用状态与控制（#78）

> 基线：`0058b7e`。本文区分规范要求、现行设计与证据边界：约束性措辞保留原文要求；现行行为和限制不自动升级为规范；测试描述不代表本次迁移已执行验证。插件所有权以[插件架构](插件架构.md)为权威。

`ApplicationService` 是 InteractionProcessor 的内部辅助对象，也是其应用变换、隐藏标志和外部控制源的唯一写入者，但不是所有窗口/后端状态的唯一写入者。其持有的 InteractionContext 实现本地运行时端口，持有窗口、配置和编辑器。模型选择与动作归 ModelProcessor 所有，只通过事件请求；模型元数据从状态事件中缓存。Delegate 只组装生命周期，绝不转发业务调用。

语音凭据和剪贴板读取编排归后端插件所有，不属于 ApplicationService 或 InteractionContext。CommandProcessor 只通过公开插件命令能力路由，不提供旧实现回退；控制面板 GUI 入口使用 IPC，不直接引用此服务。参见[插件架构](插件架构.md)和[GUI插件](GUI插件.md)。

`SetTransform` 拒绝非有限坐标/缩放值以及超出 `[0.1, 10]` 的缩放，拒绝时不改变旧值的任何部分。模型选择仅在加载成功后提交。动作请求会报告不可用选项或启动失败。表情请求拒绝表情列表中不存在的名称，但名称在列表中不保证表情已加载或能成功启动。快照是值对象，可安全用于一帧或一次响应，无需保留对运行时状态的引用。

隐藏时，运行时先要求 Qt 后端设置空输入区域，再请求释放键盘独占并排队发送输入重置事件。服务在运行时调用成功后提交隐藏标志；这不等待合成器确认或排队的按键清理，隐藏路径也不检查键盘释放结果。呈现过程根据与当前尺寸、隐藏标志及模型索引匹配的帧重建内容输入区域；没有匹配帧时，不设置内容区域。屏幕编辑使用独立的输入区域策略，可以在隐藏时保留输入。POSIX 信号处理器写入非阻塞自管道；SignalProcessor 发出普通事件，由 GUI 所有者消费。SignalProcessor 和 CommandProcessor 都不接收服务引用或回调。

目录/状态查询序列化缓存状态；热键查询/操作使用模型请求/结果事件。外部控制按通道仲裁：流式来源优先于持久来源，同一优先级内最近更新胜出。连接断开会释放该连接的控制；模型索引或实例令牌变化会清除全部控制。共享帧槽包含值形式的输入、不可变 CPU 帧及错误状态，不包含窗口或 GPU 对象。参见[插件所有权](插件架构.md)。

## 需求验收与证据边界

- 核对变换非法输入不产生部分更新，模型选择仅在加载成功后提交，外部控制遵循上述仲裁及释放规则。
- 核对命令与模型操作通过既定事件/公开能力路由，GUI 通过 IPC 访问后端；不得把 Delegate 用作业务转发入口。
- 验收必须保留隐藏提交与合成器确认、按键清理之间的边界，以及表情列表不保证启动成功的限制；本文迁移不宣称已运行测试。
