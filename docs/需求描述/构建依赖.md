# 构建依赖

根目录是 Cargo workspace，包含宿主、CLI、GPUI 控制面板、运行时、系统服务、渲染桥和动态插件。完整本地构建使用近期 Rust 工具链及根锁文件。发布包与固定 CI 镜像面向 Arch Linux x86_64。 [Cargo workspace](<../../Cargo.toml>) · [CI 运行器](<CI运行器.md>)

## 系统开发依赖

- 使用 C/C++ 工具链、CMake、EGL/OpenGL 开发库以及 Cubism Native SDK 5-r.5 和 GLEW 源码构建原生 `terminal`。设置绝对路径 `CUBISM_SDK_DIR` 和 `CUBISM_GLEW_DIR`。请遵守 SDK 和样例模型的使用条款。 [Cubism 渲染桥](<../../crates/cubism-bridge/README.md>)
- KWin 光标桥需要 sd-bus（Arch 为 `systemd-libs`）。面板需要 Wayland、FreeType、Fontconfig、XKB Common（含 X11）、XCB、X11 和 Vulkan loader。 [固定镜像依赖](<../../Containerfile>)
- 麦克风采集需要 pkg-config、PipeWire 开发文件和 bindgen 可加载的 libclang。运行语音输入还需 PipeWire 会话管理器、默认麦克风以及 `wl-clipboard`。 [语音输入](<../语音输入.md>)

## 本地构建与部署

```sh
cargo build --workspace --locked
./scripts/deploy-plugins.sh
./target/debug/deskwaifu
```

发布配置使用 `cargo build --workspace --locked --release` 和 `./scripts/deploy-plugins.sh --release`。部署脚本只复制 Cargo 已生成的插件产物。使用自定义 `CARGO_TARGET_DIR` 时，两步使用相同设置。将 SDK 与样例模型放在开发或验证环境中，运行时模型由用户单独准备。 [部署脚本](<../../scripts/deploy-plugins.sh>) · [terminal 插件](<../../plugins/terminal/README.md>)
