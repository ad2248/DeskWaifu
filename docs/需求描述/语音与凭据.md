# 语音与凭据

## 范围与基线

本文以主线提交 `0058b7e` 的实现和测试源码为依据，记录已实现行为的维护契约，不追溯未核实的需求历史。下文“应”表示验收要求；“现状”“限制”表示代码边界，不意味着新增功能已经获准。本文编写时仅核对源码，未执行构建、自动测试、真实云端合成或设备试听。

### 目标

- 通过插件能力将非空文字合成为语音，在音频真正排空后报告完成。
- 支持忙时拒绝、显式替换、关联取消及停止后的安全清理。
- 由语音插件私有管理 MiniMax 凭据，允许未配置时启动，设置接口只写密钥、不读回密钥。

### 非目标

不提供离线合成、语音识别、多供应商切换、播报队列、音频文件导出或凭据保险库。底层参数类型不等于面向用户的声音/模型配置界面；不承诺任意音频设备或云端服务持续可用。

## 可验证需求

| ID | 要求与当前实现边界 | 验收入口 |
| --- | --- | --- |
| SP-01 | 插件应提供 `speech.speak/v1`，正文类型为 `speech.speak`，`text` 必须是字符串，若有 `replace` 必须是布尔值。空白文本失败；源端拒绝长度达到 10000 的文本（`QString::size()`，不是 UTF-8 字节数）。 | `SpeechPlugin.cpp`、`SpeechProcessor.cpp`、`MiniMaxSpeechSource.cpp`；插件加载、源端测试 |

| SP-03 | 请求取消应按请求 ID 匹配，不得让迟到取消或旧源/音频回调影响新播报。终态不得重复；插件停止后撤销能力并清理源和音频。内部旧处理器调用仍兼容发送者指针协议。 | `SpeechEndpointTest.cpp`、处理器契约测试、真实模块加载测试 |
| SP-04 | 合成结束只表示输入结束，应等待音频 `Drained` 再回复 `speech.completed`；连接、协议、合成或音频失败应回复 `operation.failed`，并允许后续请求恢复。 | `SpeechPlayerTest.cpp`、`SpeechAdapterFailureTest.cpp` |
| SP-05 | 未配置密钥应允许初始化，播报返回明确失败；已配置时收到 `interaction.double_click/v1` 应以替换策略播报“姐姐，你好喵”。损坏配置应阻止初始化；运行时读取失败不得继续用缓存密钥发起新播报。 | `SpeechPlugin.cpp`、`SpeechPluginLoadTest.cpp` |
| SP-06 | `command.get_speech_settings/v1` 与 `command.set_speech_settings/v1` 应校验正文 `command` 与能力相符，拒绝无效 JSON、重复键及非法密钥。设置密钥为字符串，UTF-8 最多 4096 字节，不含 ASCII 控制字符和 DEL；空字符串表示清除。 | `SpeechSettingsTest.cpp`、真实模块加载测试 |
| SP-07 | 凭据应保存到 `<configRoot>/plugin/speech/config.json`，成功写入的文件权限为 `0600`；更新保留未知字段。写入失败或并发冲突不得应用新密钥，损坏配置不得被静默覆盖。读取不存在的配置不得创建文件。 | `SpeechSettingsTest.cpp`、`ConfigStoreTest.cpp`、真实模块加载测试 |
| SP-08 | 设置回复只应包含状态（`ok/configured/error`），不回显、广播密钥或反射请求/服务端原始错误。控制面板应查询配置状态而非取回密钥；保存发送后清空输入框，断线重连后重新查询。 | `SpeechPlugin.cpp`、`SpeechTab.cpp`；GUI 行为需独立人工验收 |

## 现行设计与维护入口

- 插件入口与注册：[SpeechPlugin.cpp](../../plugins/speech/SpeechPlugin.cpp)。业务请求经 [SpeechEndpoint.cpp](../../plugins/speech/private/processor/speech/SpeechEndpoint.cpp) 关联至 [SpeechProcessor.cpp](../../plugins/speech/private/processor/speech/SpeechProcessor.cpp)，后者处理忙、替换、取消与回复。
- 播放分层：[模块 README](../../plugins/speech/private/processor/speech/README.md)、[SpeechPlayer.cpp](../../plugins/speech/private/processor/speech/SpeechPlayer.cpp)、[AudioPlayer.cpp](../../plugins/speech/private/processor/speech/audio/AudioPlayer.cpp)。状态为 Idle、Preparing、Playing、Draining；PCM 输出不接触文本或密钥，仍在 Qt 应用线程执行，没有独立音频线程。
- 云端协议：[MiniMaxSpeechSource.cpp](../../plugins/speech/private/processor/speech/source/MiniMaxSpeechSource.cpp)。使用 WebSocket Authorization Bearer，逐阶段检查服务事件顺序，固定请求 24000 Hz、单声道、Int16 PCM；响应等待定时器为 30 秒，并在有效响应后重置，不是整个播报的总时限。
- 配置：[SpeechSettings.hpp](../../plugins/speech/SpeechSettings.hpp)、共享 [ConfigStore.cpp](../../sdk/contracts/ConfigStore.cpp)。先验证请求和最新磁盘快照，再提交，成功后更新内存。失败可保留旧内存值，但插件会在新播报前刷新并在刷新失败时拒绝播报。
- 控制面板：[SpeechTab.cpp](../../plugins/speech/gui/SpeechTab.cpp)、[SpeechTab.ui](../../plugins/speech/gui/SpeechTab.ui)。保存按钮裁去输入两端空白且不保存空输入；清除按钮显式提交空字符串。底层接口并不等同于 GUI 的裁剪规则。
- 跨模块朗读调用见 [图像识别与剪贴板朗读](图像识别与剪贴板朗读.md)。

## 失败安全与隐私边界

- 文本会发送给 MiniMax 云端，设备会播放可被旁人听见的音频；“密钥不回显”不等于“文字不出本机”。真实云端测试须明确提供测试密钥并知悉网络调用与费用风险。
- 密钥以明文存于本用户私有配置文件和运行时内存。`0600` 是文件权限边界，不是加密、系统钥匙串或对同用户/特权进程的隔离；清除当前文件内容不保证旧磁盘块或备份中的安全擦除。
- 网络与服务错误使用固定说明或数字状态码，不透传套接字错误全文或服务端消息。处理器会输出语音错误说明；维护时不得把原始响应、Authorization 或密钥插入该日志路径。
- 单条 WebSocket 入站消息上限 2 MiB，音频待写缓冲上限 8 MiB；溢出、PCM 尾帧不完整、无支持格式的输出设备均失败，不静默丢弃后假报完成。取消会清理连接和缓冲，但不承诺撤回云端已接收的文字。

## 已知限制与待确认

- 未配置时的双击不播报；配置成功只说明本地保存成功，不说明云端鉴权有效。真实云端可用性、桌面音频输出及 GUI 交互需在目标环境另行确认。
- 无自动重试、无限队列或播放完成总超时保障；云端响应等待与上层能力请求超时是不同层次。
- 运行时刷新失败时 `configured` 可能仍反映旧内存状态，应以 `ok=false` 识别失败，不应据此宣称磁盘配置有效。
- 当前基线对正在进行的云端请求没有“修改/清除密钥后立即撤回”承诺；新配置针对后续使用，不应扩写成远程撤销功能。
