- 中文、换行、Tab、首尾空白逐 UTF-8 字节一致。

## 旧 HTTP ASR 云端实测（历史记录）

用户授权读取 `/tmp/bailian`，密钥只经进程环境/SSH 加密 stdin 传递，不写入仓库、远端文件或日志。

- `/models` 可见默认模型，不代表支持 chat/completions。
- `qwen-audio-3.0-asr-flash` 向兼容 chat/completions 返回 HTTP 400，同域原生 ASR 成功。因此客户端对该精确模型在发送前解析为同域原生路径，不改 host、不失败重传；其他模型仍走兼容协议。
- 旧固定镜像中生产 NativeAsrClient 使用用户指定兼容基础端点和仓库合成 PCM 验证成功，校验 hello/world/voice/input/test，不输出完整转录。此项不冒充新镜像重复 live 结果。

## Bailian WebSocket ASR 验证入口

- 当前 live 入口使用生产 NativeAsrClient，固定请求官方流式接口对应的 `qwen-audio-3.1-asr-flash-streaming`。原指定的无后缀模型能启动任务并返回结果，但标准 `finish-task` 后最终返回 `IdleTimeout`；独立最小客户端复现，用户确认后改用 streaming 模型。
- 端点由 `BAILIAN_ASR_ENDPOINT` 显式提供：`wss://llm-y3exskfcgxgxzn23.cn-beijing.maas.aliyuncs.com/api-ws/v1/inference`；入口拒绝非 WSS 地址，旧 HTTP 实测不能证明此 WebSocket 端点或模型可用。
- CI 独立步骤读取 `secrets.BAILIAN_API_KEY` / `vars.BAILIAN_ASR_ENDPOINT`；外部 PR 不获凭据。两项均缺明确禁用，部分缺失失败，不加入普通 CTest。旧变量 `BAILIAN_OPENAI_ENDPOINT` 不再用于 live 入口；部署时需单独设置新变量，代码修改不会自动配置服务器。
- 只上传仓库合成短句，不访问麦克风/剪贴板、不输出 key 或转录全文；校验 hello/world/voice/input/test，而非仅校验非空。工作流契约测试覆盖配置缺失、凭据范围及指定模型接线。
- 本次在上述固定 CI 镜像的隔离容器中使用生产 live 入口实测 streaming 模型成功：收到任务完成事件且合成短句词语校验通过。密钥只经 SSH stdin 和进程环境传递。仓库变量 `BAILIAN_ASR_ENDPOINT` 已设置并使用现有 API key 密钥。
- Release 全量构建及普通测试门禁通过，新增 WebSocket 协议测试覆盖事件顺序、音频分块、心跳、最终句子、错误脱敏、取消、deadline 与复用；GPU/实体音频/私有模型等原有 `UNVERIFIED` 项仍不宣称覆盖。完整 PR CI 另行核验。
