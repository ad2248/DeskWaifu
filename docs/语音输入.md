# 语音输入使用说明

`voice_input` 使用 PipeWire 的默认麦克风定时录音，再将音频发送给配置的识别服务。识别成功后写入 Wayland 剪贴板，由用户在目标应用中粘贴。运行宿主的 Wayland 会话需具备 `wl-clipboard` 与可用的后台剪贴板协议。开发时先构建工作区，再部署插件。 [构建与部署](<需求描述/构建依赖.md>)

## 配置麦克风和识别服务

在共享配置 `$XDG_CONFIG_HOME/deskwaifu/config.jsonc` 的 `voice_input` 区段填写设置。默认位置为 `~/.config/deskwaifu/config.jsonc`。文件权限须为 `0600`。编辑后重启宿主以加载配置。 [共享配置](<需求描述/配置与保存.md>)

```jsonc
{
  "voice_input": {
    "endpoint": "wss://llm-y3exskfcgxgxzn23.cn-beijing.maas.aliyuncs.com/api-ws/v1/inference",
    "model": "qwen-audio-3.1-asr-flash-streaming",
    "max_recording_seconds": 60,
    "api_key": ""
  }
}
```

示例 WSS 地址属于特定业务空间。请填写账户有权访问的端点、模型和密钥。录音时长默认 60 秒，可设为 1–300 秒。设置查询返回端点、模型和时限，用 `api_key_configured` 表示密钥状态。 [字段校验](<../plugins/voice-input/src/config.rs>)

- WSS 在录音结束后按每 100 ms 一块发送 PCM，上传时长约等于录音时长。
- HTTPS 兼容接口的 `/v1` 路径会补全为 `/chat/completions`。模型为 `qwen-audio-3.0-asr-flash` 时，兼容路径改用同域的原生 API 路径。该模型通过 HTTPS 最多采集 299.75 秒，为 WAV 尾部 250 毫秒静音留出空间。
- `qwen3-asr-flash` 走 HTTPS 兼容接口时，最大可配置时长为 234 秒。超过时会在打开麦克风前报告 `recording_duration_exceeds_model_limit`。 [百炼接口](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)

## 启动和查询会话

先启动 `deskwaifu`，再通过控制面板的「语音输入」页录音或查询状态与设置。也可使用 CLI。

```sh
deskwaifucli start_voice_input
deskwaifucli get_voice_input_status
deskwaifucli get_voice_input_result --session_id ID
deskwaifucli retry_voice_input_copy --session_id ID
deskwaifucli get_voice_input_settings
```

将 `ID` 替换为启动或状态返回的字符串 `session_id`。插件保留最近一个会话，活动期间再次启动会收到 `busy`。状态返回阶段、时长、错误码和复制结果。显式结果查询可读取转录。转录超出 IPC 帧限制时，结果查询返回 `result_too_large_for_ipc`，仍可用该会话 ID 请求复制。复制失败或结果未知时可用同一命令重试。空白转录返回 `no_speech` 并保留剪贴板。 [命令和面板操作](<../plugins/voice-input/src/lib.rs>)

## 绑定快捷键

Sway 配置示例。

```text
bindsym $mod+v exec deskwaifucli start_voice_input
```

Hyprland 配置示例。

```text
bind = SUPER, V, exec, deskwaifucli start_voice_input
```

## 排查问题

- `not_configured` 或配置错误时，检查配置文件路径、权限、API key 和模型权限。
- 录音错误时，用 `wpctl status` 检查 PipeWire 会话和默认麦克风。录音失败的会话会跳过云端识别。
- 复制失败时，检查 `wl-copy` 和宿主进程的 Wayland 会话环境。可用 `wl-paste --no-newline` 读回文本。
- 录音和转录保存在内存中。转录可经显式查询和剪贴板传出，剪贴板管理器可能保留复制的文本。云端数据处理和计费由配置的服务商决定。

## 验收范围

协议测试使用本地服务验证 WSS 事件与音频分块，以及 HTTPS 请求与时长限制。录音和剪贴板的环境测试分别需要私有 PipeWire 会话和私有 Wayland 合成器。实际云端账户与物理麦克风需在目标环境各自验收。 [ASR 测试](<../plugins/voice-input/src/asr/tests.rs>) · [录音测试](<../crates/os/src/audio_input/tests.rs>) · [剪贴板测试](<../crates/os/src/clipboard/tests.rs>)
