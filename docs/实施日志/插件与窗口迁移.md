# 插件与窗口迁移摘录

## 记录身份与边界

本记录从文档重整基线 `0058b7e` 的 `plugin-architecture.md`、`gui-plugins.md`、`qt-window-backend.md`、`release-packaging.md` 提取版本相关背景；不是本次重新实施或运行的结果。原文没有为每段提供日期、提交或完整验证附件，这里不补造身份。持续规范分别见[插件架构](../需求描述/插件架构.md)、[GUI 插件](../需求描述/GUI插件.md)、[Qt 窗口](../需求描述/Qt窗口.md)及[发布打包](../需求描述/发布打包.md)。

## 插件拆分与升级

业务组装从平台转到各插件；语音凭据不再由交互层逐帧同步。旧主配置的 `minimax_api_key` 不自动导入语音插件，升级后需通过控制端重新设置；迁移不主动删除旧文件密钥，用户应自行移除。本轮原插件迁移未改变 AUR 分包和依赖元数据，这不是后来所有版本的永久承诺。

## GUI 页面布局取舍

原讨论保留现有卡片分布，不强制“一 TAB 一插件”：

- GPU 是进程级、下次启动生效的配置，与重启按钮放同页，避免拆开操作。
- 交互页负责输入响应配置，模型页负责模型操作与显示编辑，不因同属桌宠就合并。
- 位置、缩放、裁剪和应用/取消共用完整变换事务，不能拆给不同所有者。
- 外部口型幅度不生成语音，因此保留模型页，不迁入 speech。
- 当时没有朗读控件可迁移，不给 reading_clip 凭空新增页面，也不让其接管语音 API Key。

此记录解释决策背景；当前页面与所有权以需求侧为准，不在此建立另一份界面清单。

## Qt 窗口迁移

原生 Wayland/EGL 窗口后端及后端选择选项已经移除，Qt 是唯一窗口实现，旧 GLFW 最小 demo 已退役。命令名、IPC socket 和配置路径在这次窗口迁移中保持不变；这不否认更早 Waifuland 重命名迁移另有路径变更。

后续模型渲染与窗口呈现分离：显式设备 EGL context 是 offscreen 渲染目标，不是恢复原生窗口后端。客户端数组要求 compatibility profile；窗口呈现前 GL_NONE 的回归由窗口像素测试保护。第三方 Cubism 的已知退出诊断未通过修改 SDK 掩盖。

原文列出的 smoke 与集成测试是验证入口和范围说明，不是本次新增运行结果；真实桌面指针、焦点和画面质量仍需另验。

## 发布工具与历史任务

发布工具在检出旧源码标签前保存到 checkout 外，避免历史标签替换修复后的工具。重跑旧任务仍使用旧工作流；发布旧标签应从含修复的 main 新建手动运行，不能强制移动标签。具体失败与本机复验保留在[Release 578 记录](Release-578本机验证.md)，不据此声称现网镜像或新任务已通过。
