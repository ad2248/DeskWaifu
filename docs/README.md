# 项目文档

[项目首页](<../README.md>)提供安装和开发入口。按需查阅下面的使用说明和维护契约。

## 使用与集成

- Live2D 模型目录、动作、表情、输出、可见性、编辑和渲染设备。[terminal 插件](<../plugins/terminal/README.md>)
- GPUI 面板启动、插件标签页和快捷键。[控制面板](<../apps/terminal-panel/README.md>)
- PipeWire 定时录音、ASR 和 Wayland 剪贴板。[语音输入](<语音输入.md>)
- 共享 JSONC、配置保存和 Live2D 配置导入。[配置与保存](<需求描述/配置与保存.md>)
- Unix socket、CLI 信封和传输限制。[IPC 与外部控制](<需求描述/IPC与外部控制.md>)

## 开发与运维

- 插件发现、生命周期、命令和面板注册。[插件架构](<需求描述/插件架构.md>)
- 工作区依赖、Cubism/GLEW 和本地部署。[构建依赖](<需求描述/构建依赖.md>)
- 本地检查、软件渲染和验收边界。[测试与门禁](<需求描述/测试与门禁.md>)
- 固定镜像、Cargo vendor 和缓存。[CI 运行器](<需求描述/CI运行器.md>)
- PR 验收依据、审查触发与合并保护。[审查与 CI 并行](<需求描述/审查与CI并行.md>)
- 精确 tag、Arch 包、发布权限和资产校验。[发布打包](<需求描述/发布打包.md>)
- 已发布资产验证、配方更新与 AUR 子模块维护。[AUR 打包与维护](<需求描述/AUR打包与维护.md>)

更新实现时同步更新对应契约与验收入口。仍受支持的兼容接口说明当前输入、输出与限制。待实现事项放在计划中，并标明状态。验证结论注明实际环境与覆盖范围。
