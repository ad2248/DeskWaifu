# 桌面插件

`desktop.so` 拥有模型、渲染、窗口、输入和交互业务。模型与窗口共享 GPU 生命周期及
完整变换事务，保留在一个插件内；这不是平台的内置业务组装。

## 所有权

- `private/app/LAppDelegate` 只组装本插件的模型、交互、输入和信号处理器。
- `InteractionProcessor` 拥有窗口、编辑事务、可见性和外部控制状态。GUI 线程只持有
  窗口/Wayland surface、呈现 context、业务状态和只读模型元数据。
- `ModelProcessor` 是 GUI 线程上的操作代理；`ModelRuntime` 在 `model-render` 线程
  创建、更新及销毁 Cubism 模型、动作、表情、纹理与 GL 对象。
- `InputListener` 使用独立定时器采样全局光标，窗口输入通过事件投递；连续移动有界
  合并，离散事件保留顺序屏障，输入时间戳不受排队延迟影响。
- `SignalProcessor` 通过自管道将 SIGUSR1/SIGUSR2 转为普通事件。KWin 清理守护由
  本插件的独立 `deskwaifu-cursor-guard` 程序承担，不向平台入口增加业务分支。

## 呈现与停止

模型线程独立驱动渲染。线程间最多保留一个最新状态和一个最新不可变 RGBA 帧，慢
呈现不会积压帧。模型 token、尺寸、隐藏状态与视口不匹配的旧帧不被用于新输入。
GUI 定时呈现不接管平台事件循环。当前是 CPU readback/upload 路径，不承诺零拷贝。

命中回调只弱引用线程安全交换槽并读取 CPU 快照，不访问 GL 或借用业务处理器。
停止、渲染错误和模型/视口变化使旧快照失效；几何与轮廓来自同一个完成帧，但可能
领先于最后成功呈现帧。

停止时先停止生产源与命令入口，再等待模型 worker 收尾并销毁 GUI 持有的渲染表面，
最后关闭窗口。GL 析构发生在所属线程及有效 context 中；无法恢复 context 的失败
通过 SDK 诊断返回平台，不能被报告为成功退出。

## 公共协作

`DesktopPlugin.cpp` 发布 `command.<command>/v1` 能力。模型动作先检查编辑事务约束，
异步完成后才回复；请求取消不撤销已经执行的修改。变换编辑、位置、缩放与裁剪由
同一所有者授权、保存和取消。

双击只发布 `interaction.double_click/v1`，问候内容和语音替换策略由语音插件决定。
IPC 网关、语音、朗读和 OCR 均不是本插件的内部依赖。

`tests/` 保留真实 Cubism/EGL、输入策略、模型线程、GPU 收尾及窗口行为回归。
实际桌面输入与云端服务不属于普通自动测试的授权范围。
